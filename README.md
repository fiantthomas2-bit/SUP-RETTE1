# Supérette — Gestion

Application web de gestion d'une supérette : recettes, achats, dépenses, bilan financier.
Fonctionne **hors ligne** et s'installe sur Android comme une application (PWA).

## Utilisation

1. Ouvrir l'URL GitHub Pages sur Android avec Chrome
2. Menu **⋮ → Ajouter à l'écran d'accueil** (ou bouton « Installer »)
3. L'icône « S » apparaît sur l'écran d'accueil

## Fonctionnalités

- Saisie des recettes, achats et dépenses journalières
- Calcul automatique de la valeur financière restante
- Bilan financier avec bénéfice net et marge
- Graphique des recettes sur 7 jours
- Export / import des données (JSON)
- Fonctionne 100 % hors ligne

## Sauvegarde des données

Les données sont stockées dans le navigateur (localStorage) de l'appareil.
Pour ne rien perdre : **⚙ → Exporter les données**.
